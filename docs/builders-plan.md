# Floor and interior builders

Requested: tile builders for dungeon floors and house interiors.

The guild gains a 2–4 floor dungeon editor: draw 13×9 terrain, place arrival/stairs and four encounter/reward sockets per floor, configure encounters and actual funded reward types, test a synthetic run, save a profile-specific browser draft, and publish through the existing authenticated command path. Authored geometry is immutable edition data in version-3 custom module strings. This preserves the existing contract state schema and v1/v2 editions. The contract and server independently reject invalid layouts. Preview creates no economic assets.

Every house gains an 11×9 editor for terrain, arrival, the south-wall door, service station, account book and furniture. Preview uses the actual indoor movement component. Saving installs the validated layout for that house in this browser; existing gameplay stations and wallet retain their real behavior. These cosmetic layouts are browser-local across demo profiles; they are not property ownership or shared multiplayer state.

Both editors retain the current tile/avatar system. Validation requires reachable exits and stations, valid bounded geometry, non-overlapping placements and explicit saving. Paid floor rewards continue to require actual owned item funding; no speculative reward minting. Local sandbox contract upgrade preserves current assets and active state. No public transaction or deployment.
